# 2627_Project2A_SequenceurAudio
Groovebox

Description

Notre projet a pour but de concevoir une groovebox, c’est-à-dire un instrument autonome pour la production en direct de musiques électroniques basées sur des boucles. Il doit avoir une interface physique de contrôle claire simple à utiliser et on doit pouvoir sortir de l’audio.   

Fonctionnalités

-une sortie audio mini jack 3.5 
-un écran pour indiquer précisément le BPM 
-8 touches avec des leds 
-une enveloppe sur les signaux d’entrée et sorte
-des effets audio en sorte
