# 2627_Project2A_SequenceurAudio
Séquenceur Audio

Desctripiption

Notre projet a pour but de concevoir un synthé, c’est un instrument autonome pour la production en direct de musiques électroniques basées sur des boucles. Il doit avoir une interface physique de contrôle claire simple à utiliser et on doit pouvoir sortir de l’audio.   

Fonctionalité

-une sorte audio mini jack 3.5 
-un écran pour indiquer présisément le BPM 
-8 touches avec des leds 
-une enveloppe sur les signaux d’entrée et sorte
-des effects audio en sorte
